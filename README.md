# MatMan — Pénzeső Simulator

Mobilra optimalizált, magyar nyelvű, pixel-art arcade böngészős játék.

## Indítás
Nyisd meg az `index.html` fájlt böngészőben. Nincs szükség buildre, Node.js-re vagy külső függőségre.

## Irányítás
- Mobil: BALRA / JOBBRA érintőgombok
- Asztali böngésző: bal és jobb nyíl, vagy A / D
- AKCIÓ: kis hírnév-bónusz

## Játékmenet
- Zöld bankjegy: +50 000 Ft
- Arany bónusz: +150 000 Ft és hírnév
- Piros botrány: hírnévvesztés
- Időnként szatirikus közéleti villámkérdés jelenik meg
- A rekordot a böngésző helyben menti

## Cloudflare Pages
A repó gyökérkönyvtárát válaszd ki Cloudflare Pages-ben. Build command nem szükséges; a gyökérkönyvtárból szolgáld ki az `index.html` fájlt.
